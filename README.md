# 无限之翼 Alpha 8.34 F2 暂停与屏障教学测试版

本版本基于 Alpha 8.29，重点修复移动端主炮音效持续播放、武器音效叠加和后台音频状态问题。

- 主炮音效改为短促单次播放，不再保留长尾持续声。
- 主炮与无人机共用同一个武器音频池，音量一致。
- 主炮、无人机同一时间统一限流，避免多架单位重复叠加音效。
- 每个武器音效实例到时强制停止并归零，不会循环或残留。
- 切到后台、锁屏或离开页面时立即停止全部音效并暂停背景音乐。
- 回到前台后必须经过一次用户操作才恢复音频，且保留原来的音乐开关和音量。
- 背景音乐、武器、爆炸和合成音效继续独立管理。
- 保留 F2 测试模式和 Alpha 8.29 的鼠标锁定控制。


## Alpha 8.34 音频修改
- 背景音乐不再使用 HTML `<audio loop>`。
- BGM 改为 Web Audio API 解码并使用非循环 `AudioBufferSourceNode` 分段续播。
- 每段播放结束后销毁旧节点，再创建下一段，不保留长期循环媒体元素。
- 切后台、锁屏或页面隐藏时停止 BGM 节点并挂起 AudioContext。
- 返回前台后必须经过一次用户操作才按原进度恢复。
- 主炮、无人机及爆炸音效继续使用短时事件节点。

注意：请通过网站或 VS Code Live Server 测试；直接使用 `file://` 打开时，部分浏览器会阻止读取并解码 MP3。


Alpha 8.34: 移动端暂停菜单新增“开发者测试”入口，与电脑 F2 共用同一调试面板。
