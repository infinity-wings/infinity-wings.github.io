# 无限之翼 Alpha 8.67

- 主菜单移除紫色全息按钮框，改为四项无边框图标导航与底部纯文字“点击开始游戏”。
- 作战计时器缩小并移至右上角；敌弹拖尾改为更短、更细的柔和能量尾迹。
- 敌弹颜色改为固定语义：青蓝普通伤害、橙色高伤、红色致命伤害、紫色减速干扰。
- 前四个限时 Boss 超时后停止攻击、闪烁并向上加速撤离，不再直接从画面消失。
- 宽体 Boss 使用与机身轮廓匹配的椭圆命中区域，左右装甲可被子弹、激光和导弹正常命中。
- Boss 护卫节点更换为独立的飞行护盾 3D 贴图，不再显示临时五边形模型。
- 十个 Boss 统一增加高速入场、渐亮放大、推进粒子、减速停靠、能量波和震屏演出，入场完成后才开始攻击。
- 投影改为离屏缓存内仅对战机像素着色，移除紫色矩形；无人机更换为珍珠白与青色的独立 3D 贴图。

- 侦察、重装、自爆、狙击、支援、弹幕、掠袭、航母、干扰九类敌机全部使用独立的 3D 渲染贴图。
- 红色侦察机保留原设计并加宽；Boss 更换为宽体空中堡垒，不再使用细长轮廓。
- 敌机显示尺寸整体提高，并启用高质量贴图缩放；512 像素透明源图在移动端仍保持清晰边缘。

- 玩家战机装甲调整为更明亮的珍珠白与银白色，并增加驾驶舱、机身能量脊、翼端导光条和推进器动态光效。

- 玩家、普通敌机与 Boss 改为单层贴图绘制，不再与旧程序模型叠加。
- 玩家战机更换为宽翼、短机身的新模型，并移除旧细长贴图。

- 为平板增加独立 HUD 定位规则，亚空间屏障强制固定在第二行最左侧。
- 样式文件加入版本参数，避免 iPad 继续读取旧缓存布局。
- 移动端敌弹复用发射角并采用批量变换绘制，减少逐颗三角函数和画布状态切换。
- 持续低帧率时按重要性减少普通粒子与星点绘制，同时保留屏障、雷电等关键特效。

- 修正移动端菜单键重复叠加安全区偏移的问题，固定贴近游戏画面左上角。
- 重建底部 HUD 两行布局，亚空间屏障固定在第二行左侧，经验条位于其右侧。

- 修复移动端弹幕增多后敌弹退化成纯色圆点、看起来像特效消失的问题。
- 移动端敌弹发光与拖尾改为缓存图块复用；战斗状态检查改为定时执行，降低长局 CPU/GPU 压力与发热。
- 敌弹采用平台上限，达到上限后暂停生成新弹，不再突然删除场上仍具威胁的弹体。
- 高威胁敌人加入数量上限与威胁预算，避免多架弹幕载机同时封死走位。
- 镜像入侵期间所有正常刷新敌军直接使用镜像形态，不再生成真身/假身配对。
- Boss 增加 5 秒预警、顶部入场、放大模型与强化击毁演出；图鉴增加十个独立 Boss 条目。
- 移动端亚空间屏障移至 HUD 左侧并移除 B 字样；维修包按普通敌机速度下落。

- 第一个 Boss 在 2分30秒出现，之后每隔 1分30秒推进至第十个最终 Boss。
- 前四个 Boss 仅停留 30 秒；击毁获得大量经验，超时撤离且不结算奖励。
- 第五个固定为觉醒 Boss；第六至第九个每局随机一只额外觉醒 Boss，击毁掉落觉醒原核奖励。
- 第五个起 Boss 持续存在至击毁或游戏失败；第 1–4 个各 2 种攻击，第 5–9 个各 3 种，第 10 个最终 Boss 使用 5 种攻击。

- Boss 战开始时彻底清理普通敌人与敌弹，并暂停常规敌人刷新。
- 提高阶段 Boss 与觉醒 Boss 的基础耐久，并根据玩家火力动态调整。
- 经验碎片改为高速直线追踪，远距离或长时间未拾取时自动加强追赶。
- 补充 Apple Pencil 对源核、觉醒和菜单按钮的统一激活兼容。
- 玩家弹、敌弹、导弹、粒子与掉落物使用预分配、可小批扩容的对象池。

- 手机和平板保持竖屏运行，并为 iPad 主屏幕模式保留顶部安全区。
- 锁屏或切换到主屏幕时，音频会先平滑静音再暂停，避免短促爆音。
- 回到游戏后等待玩家操作，再渐入恢复背景音乐和音效。
- 主菜单背景、标题、战机和按钮会在加密连接界面提前加载。
- 每次启动后的首次出击显示一次亚空间屏障说明。
- 已移除主菜单尾焰与未引用的旧版资源。
