# 无限之翼 · Alpha 8.42 稳定性修复 F2 测试版

本版优先修复“全部源核Ⅲ级 + 无敌 + Ω危险等级”压力测试时出现的模型错位、异常放大与画面状态污染。

主要修复：
- 每帧校验战斗实体坐标、尺寸、速度和生命周期。
- 限制敌机、子弹、激光、粒子、拾取物和无人机的安全数量。
- 异常对象会被回收，不再继续污染画布。
- 每个无人机模型使用独立绘制状态，防止变换叠加。
- 敌机模型层绘制前强制重置 Canvas 状态。
- “全部全Ⅲ”后立即清理瞬时负载并重建投影/无人机缓存。
- 首页“无限之翼”后增加小号版本号 Alpha 8.42。

仍保留 Alpha 8.34 的移动端开发者测试菜单和既有功能。
