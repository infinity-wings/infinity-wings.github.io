# 无限之翼 Alpha 8.26 F2 敌机死亡渲染隔离修复测试版

本版本修复进入战斗后 1 秒至数秒内画面停止的问题。

修复内容：
- 补齐飞机姿态系统缺失的 pitch 与 thrust 初始值，防止首帧计算产生 NaN。
- 战斗帧加入异常隔离，单个对象或绘制异常不再让整个 requestAnimationFrame 主循环永久停止。
- 出现异常时自动清理坐标无效的子弹、敌人、粒子和经验点，并恢复飞机有效坐标。
- 保留 Alpha 8.20 的全部功能与 F2 开发者模式。


## Alpha 8.26 修复
- 敌机死亡爆炸、冲击波、闪电与粒子均使用独立绘图状态。
- 单个特效异常不会再中断敌机、玩家与无人机模型绘制。
- 每帧及异常恢复时强制重置 Canvas 变换、透明度、混合模式、滤镜和阴影。
- 增加核心战斗模型兜底补画，游戏逻辑继续运行时模型不会整层消失。


## Alpha 8.26 测试内容
- 无人机射击音量与主炮统一。
- 镜像入侵敌人以屏幕中线成对对称生成。
- 悬赏精英增加动态准星与目标文字。
- 陨石雨改为大型贯穿陨石，出现前显示红色路径预警，对普通敌机具有贯穿清除效果。
- 驾驶员编号仅在死亡后选择继续游戏时递增。


## Alpha 8.26 测试内容
- 陨石预警轨道整体收窄，并按陨石体积分为粗、中、细三种宽度。
- “猎杀反转”统一更名为“赏金猎杀”。
- 赏金目标改为小型Boss级单位：高血量、低移动速度、专属放大模型与三种强化弹幕。
- 赏金目标失败后主要强化火力与恢复少量生命，不再突然高速移动。
