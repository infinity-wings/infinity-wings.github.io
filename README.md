# 无限之翼 Alpha 8.59

- Boss 战开始时彻底清理普通敌人与敌弹，并暂停常规敌人刷新。
- 提高阶段 Boss 与觉醒 Boss 的基础耐久，并根据玩家火力动态调整。
- 经验碎片改为高速直线追踪，远距离或长时间未拾取时自动加强追赶。
- 补充 Apple Pencil 对源核、觉醒和菜单按钮的统一激活兼容。
- 玩家弹、敌弹、导弹、粒子与掉落物使用预分配、可小批扩容的对象池。

- 手机和平板保持竖屏运行，并为 iPad 主屏幕模式保留顶部安全区。
- 锁屏或切换到主屏幕时，音频会先平滑静音再暂停，避免短促爆音。
- 回到游戏后等待玩家操作，再渐入恢复背景音乐和音效。
- 主菜单背景、标题、战机和按钮会在加密连接界面提前加载。
- 每次启动后的首次出击显示一次亚空间屏障说明。
- 已移除主菜单尾焰与未引用的旧版资源。
