# Infinity Wings Alpha 8.4 - Public

《无限之翼》Alpha 8.4 公开版。

## 本次更新

- 主炮独立基础音量调整为 30%。
- 保留背景音乐与游戏音效的独立音量控制。
- 所有声音首次启动默认开启，背景音乐与游戏音效默认均为 50%。
- 背景音乐继续使用 3 秒淡入淡出并循环播放。
- 已移除开发者调试面板及其加载文件。
- 标题与暂停菜单版本标识更新为 Alpha 8.0 PUBLIC。

## 启动

解压后打开 `index.html` 即可运行。建议使用 Chrome、Edge 或 Safari 的较新版本。

## Alpha 7.6 调整
- 主炮音量在 Alpha 7.4 的 30% 基础上再降低 70%，最终基础音量为 9%。
- 保持公开版，不包含 F2 开发功能。

## Alpha 7.6 调整
- 主炮音量在 Alpha 7.5 的 9% 基础上再降低 90%，最终基础音量为 0.9%。
- 其他背景音乐和游戏音效音量不变。
- 保持公开版，不包含 F2 开发功能。


## Alpha 7.8 调整

- 使用用户提供的“射击.mp3”替换公开版主炮音效。
- 保留 Alpha 7.6 的主炮播放音量、背景音乐与音效音量设置。
- 公开版继续移除 F2 开发者功能。


## Alpha 7.8
- 新主炮音效的实际播放音量由 30% 调整为 6%，即在当前基础上降低 80%。
- 其余音效、背景音乐、音量滑块与公开版设置保持不变。


## Alpha 8.0

- 主炮自定义射击音效基础音量调整为 3%。
- 无人机射击音效基础音量调整为 3%。
- 背景音乐、爆炸音效、音量滑块与 3 秒淡入淡出保持不变。
- 公开版继续移除 F2 开发者功能。


## Alpha 8.0 修复
- 修复未升级主炮源核时，战术投影只有机体但不发射子弹的问题。
- 基础主炮现在始终被视为可复制的Ⅰ级攻击技能；其他攻击技能仍需实际取得。


## Alpha 8.3
- 修复手机和平板上音量滑块无法拖动的问题。
- 修复档案库及滚动区域在触摸设备上无法滑动的问题。
- 调整全局触摸拦截逻辑，保留游戏操作时防止页面误滚动，同时允许原生滑块与列表滚动。
- 增强背景音乐恢复机制：切到后台、关闭后重新进入、页面恢复与重新获得焦点时会检查并恢复音乐。
- 修复首次自动播放被浏览器拦截后，后续触摸仍可能无法重新启动背景音乐的问题。


## Alpha 8.4

- 移动端取消固定虚拟摇杆，改为游戏画面任意位置按住拖动控制。
- 飞机目标点自动保持在手指上方，减少手指遮挡。
- iPad、手机与桌面统一保持 9:16 等比例显示，不再横向拉伸。
- 加入刘海、圆角与 Home 指示条安全区域适配。
- 继续统一移动端滚动、滑块和游戏手势的事件边界，避免互相抢占触摸。
